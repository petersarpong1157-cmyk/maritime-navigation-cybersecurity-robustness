# Third-party dataset attribution

## MARSIM GPS-spoofing dataset

Original dataset:
https://zenodo.org/records/8202936

MARSIM is an independently developed simulation dataset.
Peter Sarpong did not create the original MARSIM recordings.

This repository provides an independently selected benchmark
manifest, detector settings, and numerical analysis results.

The original MARSIM PCAP recordings are not redistributed.
Processed MARSIM GPS observations are excluded pending
confirmation of the applicable redistribution conditions.

The repository's MIT License applies to original code
authored for this research. It does not relicense MARSIM
or any other third-party materials.

Users should consult the original dataset record for
its applicable license, citation, and reuse requirements.
