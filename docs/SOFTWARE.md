# Software environment

Recorded environment: R 4.5.2 on Windows 11 x64.

Required R packages for the main simulation:

- tidyverse
- caret
- randomForest
- pROC
- dplyr
- ggplot2
- readr
- tidyr

The full recorded package versions are available
in docs/R_session_info.txt.

The MARSIM benchmark also used Wireshark TShark
for NMEA extraction from the original PCAP files.

MARSIM source dataset:
https://doi.org/10.5281/zenodo.8202936

The raw MARSIM PCAP files are not redistributed.
The processed MARSIM dataset is temporarily
excluded pending clarification of reuse conditions.
